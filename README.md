# 課題0503 バグ修正

次の仕様のプログラムを，**AIが書いた** という設定で `main.c` に用意した．ところが，このプログラムにはバグがある．

> 入力された int 整数が **0 未満または 10 以上または 5** のとき「OK」，そうでないとき「NG」と表示する．

## 課題
1. `main.c` を実行して，**おかしな表示になる入力** を探せ．
2. バグを直した `main.c` を提出せよ．
3. **バグを再現する入力** (元のバグ入りコードと，正しいコードで出力が食い違う入力) を `bugs.txt` に1行1つ，**3つ以上** 書け．
   - 異なる値を3つ以上．そして「0未満」の入力と「10以上」の入力を最低1つずつ含めること．

ヒント: `&&`(かつ) と `||`(または) の意味を考え直す．AIの出力は，もっともらしくても間違っていることがある．

## 提出するファイル
- `main.c` : 直したプログラム
- `bugs.txt` : バグを再現する入力
- `ai_log.txt`

## 採点について
- push すると GitHub Actions が自動採点します。結果は Actions のログと、フィードバック用の Pull Request に出ます。
- 採点は **プログラムを実行した結果** で行います。何度でも push して再採点できます。
- `ai_log.txt`(AI利用ログ)も採点対象です(10点)。AIを使ってもかまいません。ただし **AIの答えを自分で確かめること** が課題の目的です。
